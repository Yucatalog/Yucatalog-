# Yucatalog — Catálogo Web

Catálogo en línea de accesorios con tus fotografías reales ya integradas en un solo archivo `index.html`, listo para subir a **GitHub Pages**.

## Contenido del ZIP
- `index.html`: Página completa (Tailwind CSS + Inter, buscador, filtros por categoría, carrusel interactivo, especificaciones y botón de WhatsApp `55 4013 0621`) con tus 10 fotografías reales ya optimizadas e incrustadas.
- `.nojekyll`: Asegura que GitHub Pages publique el sitio estático sin procesamiento adicional.
- `README.md`: Guía rápida.

## Cómo subirlo a GitHub
1. Extrae este archivo `.zip` en tu computadora.
2. En tu repositorio público de GitHub, haz clic en **Add file → Upload files**.
3. Arrastra `index.html` (y opcionalmente `.nojekyll`) y confirma con **Commit changes**.
4. En **Settings → Pages**, selecciona la rama `main` y carpeta `/ (root)` y guarda.
